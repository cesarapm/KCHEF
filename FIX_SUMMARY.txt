┌─ PROBLEMA ─────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Cuando recargabas http://127.0.0.1:8000/dashboard:                        │
│  • Se redirigía a http://127.0.0.1:8000/login?redirect=/dashboard         │
│  • Aunque tenías sesión activa (podías entrar sin problema)               │
│  • Al clickear en enlaces internos funcionaba bien                         │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ CAUSA RAÍZ ───────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. CACHÉ AGRESIVO (60 segundos)                                           │
│     → useAuthState.js guardaba la verificación en caché                   │
│     → Al recargar, usaba el caché sin validar con servidor                │
│                                                                              │
│  2. SIN REVALIDACIÓN EN RECARGA                                            │
│     → No había forma de distinguir:                                        │
│       - Navegación interna (no necesita validar cada vez)                 │
│       - Recarga de página (SÍ necesita validar con servidor)              │
│                                                                              │
│  3. DESAJUSTE CLIENTE-SERVIDOR                                            │
│     → El estado del navegador no se sincronizaba                           │
│     → Si la sesión expiraba en servidor, el cliente no lo sabía           │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ SOLUCIÓN ─────────────────────────────────────────────────────────────────┐
│                                                                              │
│  ARCHIVO: resources/js/composables/useAuthState.js                        │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│  ✓ Agregado parámetro forceRefresh a checkAuthentication()               │
│    → Si forceRefresh=true: ignora caché, valida con servidor            │
│    → Si forceRefresh=false: usa caché de 60 segundos                    │
│                                                                              │
│  ✓ Agregado cache: 'no-store' a todas las peticiones fetch               │
│    → Evita caché HTTP del navegador                                      │
│                                                                              │
│  ✓ Resetean flags de caché en logoutUser()                               │
│    → Garantiza validación en próximo login                               │
│                                                                              │
│  ARCHIVO: resources/js/router/index.js                                    │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│  ✓ Detecta si es RECARGA de página:                                       │
│    const isPageReload = !from.name                                        │
│    → from.name = null → es recarga                                       │
│    → from.name = "Home" → es navegación interna                          │
│                                                                              │
│  ✓ Pasa forceRefresh a checkAuthentication()                             │
│    → checkAuthentication(isPageReload)                                    │
│    → En recarga: fuerza validación remota                                 │
│    → En navegación: usa caché local                                       │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘
